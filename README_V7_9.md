# Agosto Contract Bot V7.9 — Storage + Reset Member

## 1. Склад предметів

Доданий окремий модуль:

`storage.py`

Основна команда:

`/sklad`

Команда доступна керівництву і створює / оновлює постійну панель складу
в потрібному Discord-каналі.

Якщо `STORAGE_CHANNEL_ID` не заданий, просто запусти `/sklad`
у тому текстовому каналі, де має бути склад — бот запам'ятає його.

Опціонально в Railway можна додати:

`STORAGE_CHANNEL_ID=<ID каналу 📦│склад-сімʼї>`

### Головна панель

- 🔎 Пошук
- 📦 Весь склад
- ➕ Додати
- ➖ Взяти
- 📜 Історія
- ⚙️ Керування

### Логіка

Для звичайної роботи:

`знайти предмет -> додати або взяти -> одразу бачити новий залишок`

Бот автоматично записує:
- хто зробив операцію;
- який предмет;
- скільки;
- залишок до;
- залишок після;
- дату та час.

### Пошук

Пошук працює по частині назви і не залежить від регістру,
включно з українською / кирилицею.

### Весь склад

Склад показується сторінками по 20 позицій.
Зі сторінки можна одразу відкрити картку конкретного предмета.

### Керування

Тільки керівництво може:
- створити новий предмет;
- перейменувати предмет;
- прибрати предмет зі складу.

Видалення не стирає історію рухів.

При створенні:
- назва;
- початкова кількість;
- одиниця виміру (за замовчуванням `шт.`).

## 2. Обнулення окремого учасника

Нова команда:

`/reset-member member:@Учасник`

Після вибору людини відкривається панель:

- 🏆 Рейтинг
- 💰 Заробіток
- ♻️ Все

Обнулення не видаляє стару історію.

Не змінюється:
- історія контрактів;
- історія виплат;
- баланс `До виплати` у `/payouts`.

Після обнулення бот просто починає рахувати відповідну
поточну статистику цієї людини з нового моменту.

Індивідуальне обнулення рейтингу також враховується у поточному
рейтингу та в поточному розрахунку премій.
